# Recruiter Pre-Boarding Checklist — Scranton Branch

## Offer Verification
- [ ] Signed offer letter on file (DocuSign or physical — Michael's signature must be wet-ink; he distrusts "computers doing signatures")
- [ ] Salary confirmed in HRIS (BambooHR)
- [ ] Commission plan addendum signed
- [ ] Start date confirmed with hiring manager (call Michael; do not email — he won't open it)
- [ ] Reporting structure confirmed (Regional Manager = Michael Scott, unless org chart has been updated again)

## Pre-Employment Requirements
- [ ] Background check completed (vendor: HireRight) — must clear before badge is issued
- [ ] Reference checks: minimum 2 professional references contacted
  - Reference 1: Previous manager — confirmed dates of employment, reason for leaving, rehire eligibility
  - Reference 2: Peer/colleague — confirmed work style and collaboration
- [ ] I-9 documentation collected (passport or 2-document combo) — stored in locked filing cabinet in HR annex (NOT in Dwight's desk)
- [ ] Direct deposit form submitted to payroll
- [ ] Benefits enrollment form completed (30-day window from start date)
- [ ] Emergency contact form on file
- [ ] Non-compete and confidentiality agreement signed

## Day-1 Logistics Confirmed
- [ ] Desk assigned (coordinate with Dwight — do not let Michael assign the desk, he will give away someone else's)
- [ ] IT provisioning ticket submitted (see IT Provisioning Checklist)
- [ ] Buddy assigned (see Buddy Matching)
- [ ] Welcome packet prepared
- [ ] Calendar invite sent for orientation (9:00 AM, conference room; Michael will be 20 minutes late)
- [ ] Parking instructions sent (Lot C; note the pothole near space 14)

## Output Format
Provide a concise status summary:
1. **Offer terms:** Confirmed / Discrepancy (describe)
2. **References:** Complete / Pending (names and status)
3. **Documentation:** Complete / Missing items
4. **Day-1 logistics:** Ready / Outstanding items
5. **Blockers:** Any issues that could delay the start date
